# Excel 첫 시트 분석

원본: `미국주식 같이 공부하기.xlsx` / 첫 시트 `보유 및 관심주` / 저장된 기준일 2026-08-10

- 사용 영역은 `A1:X1004`로 기록되어 있으나 실제 데이터는 주로 1~30행에 있다. `E3` 틀 고정으로 A:D와 1:2행을 유지한다.
- 병합 셀은 `A9:D9`(시총순위 TOP 7), `A17:D17`(관심), `K2:L2`(고점대비)다.
- 실제 헤더: 티커, 주식명, 업체, 시총, PE, EPS, 현재가, 전일대비, 52고점, 고점대비, 보조 막대, 2023/2022/2021/2020 MDD, 52저점, 저점대비, 년초가, 년초대비, 3개월/1년/3년/5년 스파크라인.
- GoogleFinance 수식은 시총·PE·EPS·현재가·전일 변동률·52주 고저·연초가를 가져온다. 고점/저점 대비와 YTD는 셀 수식으로 계산한다.
- MDD는 수동 값이며 연도별 고정 열이다. V1에서는 `stock_annual_drawdowns(ticker, year, mdd)`로 정규화한다.
- 20개 고유 티커: QQQ, AAPL, TSLA, SPY, DIA, MSFT, GOOGL, AMZN, META, NVDA, SOXX, AMD, TSM, LCID, RIVN, U, ADBE, DIS, NFLX, O.
- 품질 이슈: 일부 1/3/5년 스파크라인은 `#REF!`이며 여러 행이 `$B$4`(AAPL)를 잘못 참조한다. 원본의 MDD 연도도 V1 요구(현재 포함 최근 3년)와 다르다. 원본 캐시에는 분할/기간 기준 검토가 필요한 극단적 YTD 값도 있어 라이브 데이터로 간주하지 않는다.

V1 HOME은 원본의 식별·가치·가격·고저·MDD·YTD 흐름을 보존하되, 요구사항에 따라 ATH/ATL과 최근 3개년 MDD를 명시적으로 추가한다. 원본에 없는 값은 임의 생성하지 않고 `null`로 표시한다.
